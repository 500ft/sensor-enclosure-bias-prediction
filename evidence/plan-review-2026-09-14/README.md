## Finding 1: generation overwrites inputs before collision refusal

Source: [main()](../../analysis/colocation_rehearsal.py) calls `write_inputs()`
before `rehearse()` reaches the output-collision check in `snapshot()`.
The existing tests cover occupied outputs through `rehearse()`, but not the
generation-mode CLI's preceding writes.

From the checkout root with Python 3.11, reproduce entirely in a temporary
directory. The first run deliberately uses a different synthetic bias, so an
overwrite cannot hide behind identical generated bytes.

```sh
python - <<'PY'
from datetime import datetime, timezone
from pathlib import Path
from tempfile import TemporaryDirectory
import hashlib
import json
import subprocess
import sys
from analysis.colocation_rehearsal import generate, write_inputs, rehearse

with TemporaryDirectory(prefix="enclosure-review-") as temporary:
    out = Path(temporary).resolve()
    rows, metadata, known = generate(
        datetime(2026, 1, 1, tzinfo=timezone.utc), bias_c=2.0)
    csv_path, metadata_path = write_inputs(rows, metadata, out)
    report = rehearse(csv_path, metadata_path, out, known)
    names = ["rehearsal.csv", "rehearsal.metadata.json", "rehearsal.json",
             "snapshot/input.csv", "snapshot/input.metadata.json"]
    def hashes():
        return {name: hashlib.sha256((out / name).read_bytes()).hexdigest()
                for name in names}
    before = hashes()
    result = subprocess.run(
        [sys.executable, "-m", "analysis.colocation_rehearsal",
         "--out-dir", str(out)], capture_output=True, text=True)
    after = hashes()
    print(json.dumps({
        "initial_classification": report["intake"]["classification"],
        "initial_known_answers_ok": report["comparison"]["all_ok"],
        "rerun_exit": result.returncode,
        "changed_files": [name for name in names if before[name] != after[name]],
        "source_csv_matches_saved_report":
            after["rehearsal.csv"] == report["csv_sha256"],
        "snapshot_csv_matches_saved_report":
            after["snapshot/input.csv"] == report["csv_sha256"],
    }, indent=2))
PY
```

Observed at the base (the plan leaves this defect unfixed):

```json
{
  "initial_classification": "SYNTHETIC_ONLY",
  "initial_known_answers_ok": true,
  "rerun_exit": 5,
  "changed_files": ["rehearsal.csv", "rehearsal.metadata.json"],
  "source_csv_matches_saved_report": false,
  "snapshot_csv_matches_saved_report": true
}
```

The old report and saved snapshot are byte-unchanged. The original CSV/metadata
are replaced despite a refusal message. This is sufficient to prioritize the
bounded A1 repair; it does not establish loss of the saved snapshot or an exploit
involving concurrent writers. The later regression should require an unchanged
recursive manifest, not this observed failing behavior.

## Finding 2: combined illustrated assumptions can reverse the ranking

Sources: [thermal_bias.py](../../analysis/thermal_bias.py)'s `ASSUMPTIONS`,
`build_variants()` and `sensitivity_block()`, and the
[existing sensitivity interpretation](../../analysis/thermal_bias_results.md).
The repository already cautions that one-at-a-time sensitivity does not establish
robustness to combined uncertainty. This calculation makes the planning
consequence concrete using the same solver and the existing illustrated values.

```sh
python - <<'PY'
from dataclasses import replace
from analysis import thermal_bias as model

inputs = {name: value for name, value, *_ in model.ASSUMPTIONS}
variants = {variant.vid: variant for variant in model.build_variants()}
solar, wind = 1000.0, 0.5
air = inputs["T_air"]
sky = air - inputs["T_sky_offset"]
h = model.h_external(wind, inputs["h_free_floor"], inputs["h_wind_slope"])

def bias(variant, calm_preheat):
    preheat = model.shield_air_preheat(
        wind, calm_preheat, inputs["preheat_wind_halflife"], forced=False)
    return model.solve_surface_temperature(
        variant, solar, air, sky, h,
        air_preheat_k=preheat * solar / 1000.0) - air

painted = bias(variants["V0P"], 0.0)
nominal = bias(variants["V1"], inputs["shield_air_preheat_calm"])
combined = bias(replace(variants["V1"], solar_factor=0.30, conv_boost=1.0), 2.4)
for label, value in (
    ("V0P bias", painted), ("V1 nominal bias", nominal),
    ("V1 combined-scenario bias", combined),
    ("nominal absolute-bias advantage", abs(painted) - abs(nominal)),
    ("combined-scenario absolute-bias advantage", abs(painted) - abs(combined)),
):
    print(f"{label}: {value:.4f} degC")
PY
```

Observed:

```text
V0P bias: 4.4796 degC
V1 nominal bias: 3.0025 degC
V1 combined-scenario bias: 6.0327 degC
nominal absolute-bias advantage: 1.4771 degC
combined-scenario absolute-bias advantage: -1.5531 degC
```

This is an illustrative scenario, not a measured parameter set or a statement
that the combined values are probable. It changes three V1 assumptions together
while retaining the painted comparator and all other defaults. It motivates
the bounded A3 scenario package and measurement priorities. It neither proves
physical inferiority nor supplies joint uncertainty bounds or a validation band.
