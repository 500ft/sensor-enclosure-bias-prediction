# tetreault2023cci: Airtightness Measurement of Display Cases and Other Enclosures

**Source:** https://www.canada.ca/en/conservation-institute/services/conservation-preservation-publications/technical-bulletins/airtightness-measurement-display-cases.html
**Evidence boundary:** Government technical bulletin; not peer reviewed. Read in full.

## Sensors

CO2 sensors for tracer decay.

### Pros

- Written protocol with fit criteria and reproducibility.

### Cons

- Built for nearly sealed cases measured in air changes per day.

## Physical Box, Materials, and Geometry

Display cases 0.063 to 1.28 m3.

### Pros

- Start at 3000 to 6000 ppm, fit at least 20 points with R2 above 0.990, run a mixing fan only for the first 5 to 10 minutes.
- Reproducibility about 14 to 20%.

### Cons

- A vented sensor box exchanges air in minutes, so the test needs a fast sensor and a short run.

## Selection Lessons for This Project

- Supports CO2 tracer decay as the air-exchange test for each vent configuration.
